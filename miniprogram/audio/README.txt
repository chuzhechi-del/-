【背景音乐 - 使用云存储】

本小程序背景音乐从「微信云开发 - 云存储」加载，一打开首页即自动循环播放。

配置步骤：

1. 打开微信开发者工具，在顶部点击「云开发」，进入云控制台。

2. 左侧点击「存储」→「上传文件」，选择你的背景音乐 MP3 文件上传。

3. 上传完成后，在文件列表中找到该文件，点击后复制「文件 ID」
   （格式类似：cloud://环境ID.xxx/文件名.mp3）

4. 打开代码文件：miniprogram/pages/index/index.js
   在文件顶部找到：const BGM_CLOUD_FILE_ID = '';
   把单引号中间填上你复制的文件 ID，例如：
   const BGM_CLOUD_FILE_ID = 'cloud://xxx-xxx.xxxx/bgm.mp3';

5. 保存代码，在微信开发者工具中重新「编译」并「预览」即可。

注意：请确保已在 app.js 中完成云开发初始化（wx.cloud.init），
且当前小程序已开通云开发并选择了环境。
